# 📚 XYZ Bookstore - Tarjetas de Productos y Botones

Estructura de página web desarrollada en **HTML5** para una librería en línea (*XYZ Bookstore*). Este proyecto demuestra cómo organizar tarjetas de productos (*product cards*), botones de llamado a la acción (*Buy Now*), e interfaces de navegación para el carrito de compras y la caja (*checkout*).

---

## 🚀 Características

* **Estructura de Tarjetas (Cards):** Layout organizado para la presentación de libros con título, descripción y botón de compra.
* **Botones Interactivos:** Uso de la etiqueta `<button>` con clases e identificadores únicos (`id` y `class`) listos para vincular con estilos CSS o scripts en JavaScript.
* **Diseño Adaptable (Responsive):** Configurado con la etiqueta `<meta name="viewport">` para garantizar una correcta visualización en teléfonos móviles, tabletas y computadoras.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5** (Marcado y estructura semántica)
